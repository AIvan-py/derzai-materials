# Как пересобрать страницы для GitHub

Из папки `Сайт`:

```bash
python3 build.py                                   # сайт из документов проекта → Дерзай.html
python3 ../Онлайн-школа/Идеи/build.py              # банк идей → Банк_идей.html
python3 compat.py Дерзай.html github/.build/site.html                         # версия для старых Safari (ES5)
python3 compat.py "../Онлайн-школа/Идеи/Банк_идей.html" github/.build/bank.html
cd github
python3 encrypt.py .build/site.html index.html "$(cat ПАРОЛЬ.txt)" "Материалы школы «Дерзай»" "Материалы школы для чтения. Введите пароль." "Дерзай"
python3 encrypt.py .build/bank.html bank.html "$(cat ПАРОЛЬ.txt)" "Банк идей «Дерзай»" "Банк идей для курса. Введите пароль." "Банк идей"
git add -A && git commit -m "Обновление материалов" && git push
```

- Пароль лежит в `ПАРОЛЬ.txt` (в git не попадает). Чтобы сменить пароль, измените файл и пересоберите обе страницы.
- Для `compat.py` нужен Node и Babel в `github/.tools` (ставится один раз: `cd github/.tools && npm install @babel/core @babel/cli @babel/preset-env`).
- После смены пароля на устройствах, где стояла галочка «запомнить», страница снова спросит пароль.
- Удалить всё из интернета: `gh repo delete AIvan-py/derzai-materials --yes`.
