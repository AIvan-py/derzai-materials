# Дерзай — материалы для чтения

Две страницы, зашифрованные паролем прямо в браузере (PBKDF2-SHA256 + AES-256-CBC). Без пароля содержимое не читается.

- `index.html` — материалы школы: исследование, занятия, инструменты, план Сэма.
- `bank.html` — банк идей (623 карточки с фильтрами).

Страницы собираются скриптами из основной папки проекта (`Сайт/compat.py` → версия для старых Safari, `Сайт/github/encrypt.py` → шифрование). Пароль хранится только у автора.
